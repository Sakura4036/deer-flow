# DeerFlow 回放系统

DeerFlow 回放系统允许用户回放和保存与系统AI代理的对话。这个功能对于调试、演示和展示DeerFlow功能特别有用，无需实时连接AI服务。回放系统能够精确地重现代理响应、研究活动和用户交互，就像它们在原始对话中发生的那样。

## 系统概述

回放系统通过以下方式工作：

1. 自动记录实时对话中的所有事件流
2. 将这些事件保存为标准化的回放文件格式
3. 提供UI界面浏览和管理所有可用的回放文件
4. 允许用户手动保存当前对话为回放文件

## 回放文件格式

回放文件存储在 `web/public/replay` 目录中，遵循服务器发送事件(SSE)格式。每个文件中的每个事件代表原始对话中的消息块、工具调用或工具调用结果。

每个事件包含：

1. 一个 `event` 行，指定事件类型
2. 一个 `data` 行，包含事件数据的JSON负载

事件类型包括：

* `message_chunk` - 包含代理发送的消息片段
* `tool_calls` - 表示代理调用工具的时刻
* `tool_call_result` - 包含工具调用的结果
* `interrupt` - 表示用户中断流程的点

## 自动保存功能

系统会自动将每个对话保存为回放文件：

1. 在 `/api/chat/stream` 端点中，每个生成的SSE事件都会被记录
2. 事件被写入到以对话ID命名的文件中
3. 文件保存在 `web/public/replay` 目录中

## 回放列表功能

用户可以通过UI界面浏览所有可用的回放文件：

1. 回放列表显示在聊天页面的左侧
2. 列表可以展开或折叠
3. 每个回放项目显示标题、创建时间和文件大小
4. 点击回放项目可以加载并开始回放

## 手动保存功能

用户可以手动将当前对话保存为回放文件：

1. 在对话过程中，点击"保存回放"按钮
2. 在弹出的对话框中输入回放标题（可选）
3. 系统会将当前对话保存为回放文件
4. 保存成功后会显示通知

## API端点

回放系统提供以下API端点：

* `GET /api/replay/list` - 获取所有可用回放文件的列表
* `POST /api/replay/save` - 手动保存当前对话为回放文件

## 前端组件

回放系统包含以下前端组件：

* `ReplayList` - 显示所有可用回放文件的列表组件
* `SaveReplayButton` - 用于保存当前对话为回放文件的按钮组件

## 使用方式

### 浏览回放列表

1. 在聊天页面左侧查看回放列表
2. 可以点击展开/折叠按钮控制列表显示
3. 点击刷新按钮获取最新的回放列表

### 开始回放

1. 在回放列表中点击要回放的对话
2. 系统会加载回放文件并显示回放控制界面
3. 点击"播放"按钮开始回放
4. 可以使用"快进"按钮加速回放

### 保存回放

1. 在对话过程中，点击输入框上方的"保存回放"按钮
2. 在弹出的对话框中输入回放标题（可选）
3. 点击"保存"按钮确认保存
4. 系统会将当前对话保存为回放文件，并显示成功通知
